# BSA Hash Sakshya Manager

**BSA Hash Sakshya Manager** is an open-source software tool designed for investigation agencies including, but not limited to, Police, CBI, ED, Courts, Advocates, and Judges. It enables users to compute, compare, and generate hash certificates for digital evidence, ensuring the integrity and authenticity of data in legal and investigative processes.

This tool provides a secure, efficient, and transparent way to handle digital evidence in investigations and court proceedings.

---

## Features

- **Hash Calculation:** Compute the hash of files and documents to ensure data integrity.
- **Comparison Tool:** Compare hashes of original and duplicate files to verify authenticity.
- **Hash Certificate Generation:** Automatically generate hash certificates for digital evidence.
- **Multiple Hash Algorithms Support:** Supports MD5, SHA-1, and SHA-256 algorithms.
- **User-Friendly Interface:** Easy-to-use interface suitable for both technical and non-technical users.
- **Security:** Ensures the security of digital evidence and prevents tampering.

---

## Target Audience

- Police and Investigation Agencies
- CBI, ED, and other law enforcement organizations
- Courts, Advocates, and Judges handling legal evidence
- Anyone requiring secure and verifiable management of digital evidence
